# Interview Radar - Frontend

Minimal Next.js app scaffolded for the 2-hour MVP demo.

Quick start:

```bash
cd frontend
npm install
npm run dev
```

Notes:
- Uses Next.js app router structure under `/app`.
- Tailwind is configured; run `npx tailwindcss init` if needed when installing.
- The `/app/analyze` route simulates a 6–8s scan then navigates to `/results`.
